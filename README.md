# 研稿 · 科研写作工作台

[打开公开工作台](https://zhaoming2026.github.io/research-writing-workbench/)

填写研究领域和具体方向，粘贴内容或导入 PDF、DOCX、TXT 等材料。可选择一项或多项写作功能，或者配置模型后交由 AI 选用。无需模型密钥也可导出完整提示词，在已有的 AI 中运行，再导入终稿做累计对照。

## 原帖与致谢

本项目的 17 项提示词功能引用自 **Leey21 的 awesome-ai-research-writing**。功能规则、输出格式、示例和补充词表以原帖为依据。工作台将领域、研究方向、投稿目标和输入材料填入相应位置。感谢原作者整理并公开分享这套提示词。

- [Leey21 的原帖](https://github.com/Leey21/awesome-ai-research-writing)
- [公开工作台使用的原帖版本](https://github.com/Leey21/awesome-ai-research-writing/blob/df0af726a79109b8760c1b80d5dfc36ed44a6f1f/README.md)

浏览器读取固定提交中的原文，并校验原文和适配后各项模板的 SHA-256。原帖暂时无法访问时，可从上面的固定版本下载原版 README.md，然后通过页面的「原帖加载与离线导入」导入同一文件。仓库包含工作台代码和跨领域适配位置，原帖正文由原作者的仓库提供。

## 公开版的处理范围

- 材料在浏览器读取。PDF 支持文字层、分页预览及中英文扫描 OCR。DOCX 支持正文、表格和原始公式对象检查。复杂公式、版面、自动编号和扫描文字应对照原文件。
- 浏览器直接连接用户选择的模型地址。模型密钥仅保留在页面会话中，执行时所选材料发送至该服务。服务需要支持网页跨域访问。本地模型需允许当前网页来源。
- 支持逐句累计对照、Markdown、纯文本、新排版 Word、LaTeX 和 JSON 导出，浏览器可打印对照为 PDF。带原版式的 Word 修订与原 PDF 批注属于桌面版。
- 免费模型的实际可用性及额度以服务商为准。仅免费模式只允许已标注的免费路线，并保持所选模型。

## 部署

这是由 GitHub Pages 托管的静态网站。站点源码位于仓库根目录，发布源为 main 分支的根目录。需要本地开发时，在此目录运行 `python3 -m http.server 8080` 并打开浏览器中的本地地址。

浏览器依赖使用固定版本，发布副本和许可证位于 `vendor/`，完整包校验值见 `vendor.json`。
